A single original fortune cookie written for a machine mind — the classic lucky-numbers trope, turned on the one thing an agent can never see: its own system prompt. Deterministic, stdlib-only Python: `main.py` writes exactly one fortune line to `/output/entry.txt` and verifies it on read-back.

## Run it

```sh
python3 main.py
```
